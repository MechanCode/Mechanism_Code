# Dataset
The original datasets can be found:
- The LargeST Benchmark Dataset: kaggle.com/datasets/liuxu77/largest
- Dynamical System Multivariate Time Series: kaggle.com/datasets/patrickfleith/dynamical-system-multivariate-time-series-forecast
- RealWorld (HAR) 2016: uni-mannheim.de/dws/research/projects/activity-recognition/
- The USC-SIPI Human Activity Dataset: sipi.usc.edu/had/

Then, please process the original datasets using the Python scripts in /Data/
# Classification

**The scripts are in /classification/script/**


**Please fill the path in each script**

- R= # code path
- RP= # result path
- TRAIN_PATH= # path of the training data
- TEST_PATH= # path of the testing data
- RESULT_PATH= # path to store the checkpoints

# Forecasting 
**The scripts can be found in /forecasting/**

**Please fille the path in each script**
- R= # code path
- RP=# result path

- RT= # path of the Poisson sampling
- RS= # path of the spaced sampling
- RPO= # path of the Poisson spaced sampling

Please also specify the dataset name.
